## 2. 实践项目建议

### 项目 1: 自定义钩子开发
**难度**: 初级
**时间**: 3-5天

**目标**: 创建一个自定义钩子，用于在代码编辑前自动格式化代码。

**步骤**:
1. 创建一个新的钩子文件 `src/hooks/custom-formatter/index.ts`
2. 实现 `tool.execute.before` 钩子，拦截 edit/read 工具调用
3. 在编辑前调用代码格式化工具
4. 在主插件中注册新钩子
5. 测试功能并验证效果

```typescript
// 示例代码框架
export function createCustomFormatterHook(ctx: PluginInput) {
  return {
    "tool.execute.before": async (input, output) => {
      if (input.tool === "edit") {
        // 获取原始代码
        const originalCode = input.args.content;
        
        // 执行格式化
        const formattedCode = await formatCode(originalCode, input.args.filePath);
        
        // 更新参数
        output.args.content = formattedCode;
      }
    }
  };
}
```

## 4. 常见问题与解决方案

### 问题 1: 配置不生效
**可能原因**:
- 配置文件路径错误
- JSON 语法错误
- 配置项名称错误

**解决方案**:
- 检查配置文件格式
- 验证 JSON 语法
- 参考配置 schema

### 问题 2: 钩子不执行
**可能原因**:
- 钩子被禁用
- 事件类型不匹配
- 条件判断不满足

**解决方案**:
- 检查 `disabled_hooks` 配置
- 验证事件处理函数
- 确认执行条件

### 问题 3: 代理无法正常工作
**可能原因**:
- 模型配置错误
- 工具权限问题
- API 密钥缺失

**解决方案**:
- 检查模型配置
- 验证工具权限设置
- 确认 API 访问权限
